# 管理台与接入

四页管理台与对应 API 通过 180 项本地单测（含 2 项 Chromium 浏览器 UI 测试）、20 项真实宿主 SDK 隔离契约、隔离实模 EXA 联网冒烟及独立 Docker/runsc 运行时验收。真实平台群文件读取与指定测试群外发仍在联调前受线上红线约束。

## 四个页面

| 页面 | 当前可用操作 |
|---|---|
| 现场 | 线程列表、过程原文、上下文构成、结果、递纸条与停止 |
| 能力 | 编辑档案说明、TOML 配置、笔记和全局技能；克隆、历史、回滚、档案包 |
| 记忆 | 编辑会话关系、近况和主动性说明；检索自身经历，查看工作区检查点与意图 |
| 设置 | 会话范围、活动预算、主动度与睡眠、沙箱并发与参数、凭据录入/删除、MCP 与事件通道、执行状态 |

页面全部内联，通过宿主 `window.maibot` 调用静态 API。管理操作复用宿主登录，API 不向其他插件公开；签名事件 API 单独开放，但仍验证通道签名。页面不发外部网络请求，查询与操作串行进行；现场页单路轮询，为用户操作保留第二个并发槽。

管理员名册继承宿主。管理页设置保存在插件目录外的 `data/maisya/settings.json`，并在 `data/maisya/settings.base.json` 记录上次同步的 `config.toml` 基线：插件重载或版本化配置更新时，对 `settings.base.json`、`settings.json` 与 `config.toml` 执行三路合并——管理台单独改过的字段在 `config.toml` 未变动时保留，而直接在 `config.toml` 修改的字段在重启或更新后立即生效。数据库、凭据、档案、记忆与工作区统一留在外部数据目录。

容器沙箱支持在 `[sandbox]` 配置并发容器上限 `max_concurrent`（默认 `2`，范围 `1..8`）；对应默认镜像 `maisya-sandbox:py313` 由仓库根目录的 `sandbox/Dockerfile` 与 `sandbox/build_image.sh` 提供（默认 dry-run，`--execute` 执行构建）。联网功能依赖宿主模型配置中将联网服务分配给 `[model_task_config.web_search].model_list`。

宿主插件列表决定是否加载插件；管理页开关控制 Maisya 活动。卸载时会取消并等待管理请求与事件接收收束，再清理线程和执行器。前端共用源码为 `webui/management.html.in` 与 `webui/fragments/`，运行 `python3 webui/build.py` 输出三个自包含页面；`--check` 核对产物，安装使用时不需要构建。

## 编辑与档案包

保存和回滚使用当前版本号。版本冲突不会覆盖正文；“读取最新”把旧草稿留在下方，管理员核对后再保存。切换能力或记忆文档时，本页保留未保存草稿。

导出的档案包包括说明、配置、笔记、预设资产与绑定技能。技能随包放在该档案的 `preset/skills/`，不覆盖本机的全局技能库；已有同名全局技能优先使用。含服务、私有凭据或指定范围的导入档案默认 `bound=false`，核对本机绑定后才启用。

宿主 iframe 只有 `allow-scripts`，禁止直接下载文件。因此导出提供可复制的包文本，可在另一份 Maisya 中粘贴导入；已有 ZIP 可以通过文件选择器导入。API 按 24 KiB 分块传输，最多同时保留四份传输、五分钟过期；ZIP 最大 8 MiB，解压后总计最大 16 MiB、最多 256 项。凭据值不进入档案包。

## 自身活动

```json
{"action":"start","profile":"scout","owner":"self","workspace":"海岸旅行","message":"沿着海岸探索一个有意思的地点"}
```

自身活动统一使用 `self` 归属与命名空间，可以从不同启用会话续接同一个线程。普通 `send`、显式 `steer`、`stop`、检索和 Pulse 续接均可使用。`share` 把结果交到当前会话，准确链接与已声明附件走原生交付；去重按结果版本和目标会话分别记录。

自身活动只调度公开、无私有凭据、无指定用户/会话限制的能力。原会话引用和 `from_threads` 不可带入自身活动；已知会话记忆片段及个人/主机标识也会在输入检查时拒绝。会话关系继续留在原会话，自身公开结果进入七天近况，完整经历保留在线程中。自身线程的 `thread_later` 继续推进活动，不直接向群发消息。

## 指定可用范围

在能力配置中设置：

```toml
access = "listed"
allow_users = ["qq:123456789"]
allow_chats = ["会话编号"]
```

两类列表同时存在时取交集。用户列表核验真实发言人，平台使用小写、用户 ID 保持原样；攒批后的上下文 `user_id` 不授予权限。仅限制会话、没有用户列表的普通能力可在该会话自主调用。管理员能力仍需要真实管理员消息。

限制在请求前的档案展示、启动/续接/停止、检索、引用输入和模型/工具执行边界检查。检索受限线程时提供 `source_msg_id`。权限变化后旧线程不能沿用原来的宽权限；私有工作区也不能通过修改档案范围向另一批用户开放。

## MCP 与平台文件

先在保险箱录入凭据，再在服务登记中填写句柄。程序及参数由管理员固定登记，只在 Agent 调用时启动。Linux MCP worker 降权运行，程序和依赖须允许该运行账户读取；秘密由执行边界注入，不交给模型。

平台仅返回 `file_ref` 时，可以登记可信文件读取器：

```json
{
  "servers": {
    "platform_files": {
      "command": ["/opt/maisya-services/bin/python", "/opt/maisya-services/reader.py"],
      "tools": ["read_file"],
      "readonly": true,
      "credentials": {"PLATFORM_TOKEN": "platform_token"}
    }
  },
  "templates": {},
  "inputs": {"qq": {"service": "platform_files", "tool": "read_file"}}
}
```

对应 maker 档案需要授权 `mcp=["platform_files"]` 和 `mcp_call`。读取器接收 `{message_id,file_ref}`；`file_ref` 原样来自宿主原会话消息，不作为宿主文件路径解析。工具应返回单个 MCP 二进制资源：

```json
{"content":[{"type":"resource","resource":{"uri":"file:///input.csv","mimeType":"text/csv","blob":"文件字节的base64"}}]}
```

文件实体进入该线程只读 `in/`，模型只获得路径和来源；输入不会自动变成结果附件。没有配置读取器时，返回具体缺失原因。测试已实际启动 stdio 读取器验证这条链；上述协议不预设任何平台适配器的鉴权和下载 API，真实平台读取程序与凭据需按实际环境登记。

## 外部事件

在保险箱录入签名密钥，再登记固定通道：

```json
{"news":{"target":"chat:会话编号","kind":"proactive","secret_handle":"event_key"}}
```

`proactive` 经主动度、睡眠、熟人、额度与未回不连戳检查。`silent` 还需绑定原目标公开线程的 `thread_id`，仅推进线程；需要真实用户授权的档案不能通过事件获得权限。事件内容不能指定目标、管理员来源或能力权限。

接收 API 为 `maisya_incoming_event(channel,event_id,timestamp,payload,signature)`，也绑定在设置页 `incoming_event` action。HTTP 路径为宿主已有的：

```text
POST /api/webui/plugins/runtime/webui/chartyr.maisya/settings/actions/incoming_event
Cookie: maibot_session=<宿主登录凭据>
Content-Type: application/json
```

请求体为 `{"args":{...接收API的五个参数...}}`。`payload` 是 JSON 字符串，只接受 `reason` 和可选 `data`；最多 16 KiB。时间为 Unix 秒，与接收端相差不超过五分钟。签名算法：

```python
envelope = {
    "channel": channel,
    "event_id": event_id,
    "timestamp": timestamp,
    "payload": payload,
}
canonical = json.dumps(envelope, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
signature = hmac.new(secret.encode(), canonical.encode(), hashlib.sha256).hexdigest()
```

密钥由调用方自己的安全存储提供。相同通道和事件编号重复投递返回同一个 Intent；改动内容后重用编号会被拒绝。回执与 Intent 在同一事务提交，重启不会把同一事件重新创建一次。

该入口继续要求宿主认证，不新开端口；无法携带宿主认证的第三方平台需要可信转发器接入。当前已验证 API 签名、时效、去重与 Intent 转换，真实外部 HTTP 投递尚未运行。
