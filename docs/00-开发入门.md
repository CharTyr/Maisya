## 本地开发环境（macOS）

直接复用本机已建好的 Python 3.13 + `maibot_sdk` 虚拟环境 `~/.venvs/maiwork`（内含 `pytest`、`pytest-asyncio`、Playwright Chromium 与 Node）：

```bash
source "$HOME/.venvs/maiwork/bin/activate"
cd /Users/char/Documents/Projects/Maisya
PYTHONPATH=plugin/CharTyr_Maisya python -m pytest tests -q -rs -p no:cacheprovider
```

## 真实宿主契约测试（服务器隔离目录，绝不碰线上 `plugins/`）

每次修改 `_manifest.json`、`webui.json`、插件生命周期或组件注册后，必须在唯一隔离目录跑 `tests_host/`：

1. **CWD 必须是隔离目录**（`/tmp/maisya-ci-$(uuidgen)`，`umask 077`），绝不能在宿主根目录下直接跑（否则会污染线上 `logs/`）。
2. 宿主根目录仅只读加入 `PYTHONPATH`，`TMPDIR` 与 `HOME` 指向隔离目录，跑完清理隔离目录。
