# 功能详解

[← 回到 README](../../README.md)

装上 `Maisya v0.3` 之后，它在群聊、管理员私聊、条件盯梢与四页工作台里是怎么配合 MaiBot 干活的。

---

## 一、MaiBot 当主脑，Maisya 补齐手脚与持续现场

和额外塞一个新机器人不同，Maisya 的全部设计都绕着一个中心转：**MaiBot 自己的 `planner` 就是唯一主脑与唯一发言人**。

- **日常聊天不改味**：群友聊天、接梗与人际记忆继续走 MaiBot 原生流程与宿主 `A_Memorix`，Maisya 在消息接收后仅记录可信来源，不打断聊天节奏。
- **需要干活才调线程**：当 MaiBot 判断需要联网核实、写稿作图、执行工作区脚本或长线跟进时，调用 `maisya_agent` 派给线程；20 秒内完成直接拿回结果，超时转后台完成后再唤醒原会话 `planner`。
- **结果回到原人设说话**：
  - **纯文字结论**：单次垫入 MaiBot 原生回复，完全沿用它本来的口吻、拆句与表达习惯；
  - **准确链接、图片海报或群文件**：由 `planner` 调用 `share` 生成开场并精准交付，不丢失或损坏链接与附件（跨容器环境自动触发 NapCat `base64://` 群文件兜底）。

## 二、单一全能 `default` 主档案与 Hermes 渐进定制

### 1. 开箱即用的全能 `default` 主档案

`v0.3` 不再要求用户在 `scout` / `maker` / `digest` 之间来回挑选或预配置：

- **默认自带唯一全能 `default` 档案**：默认打开全部 **5 大工具集（`TOOLSETS`）**，从查证资料、读取聊天和记忆、生成网页/图卡报告、跑工作区代码到安排后续提醒与盯梢一站覆盖。
- **历史别名平滑兼容**：若过往流程或定时里保留了 `scout` / `maker` / `digest` 名称，且数据目录未单独覆盖，系统透明将其路由到 `default` 主档案继续跑通。

| 工具集 | 名称 | 涵盖能力 |
|:-----|:-----|:-----|
| `context` | 会话与记忆感知 | 读取聊天流、指定消息、人物与 `A_Memorix` 记忆、历史线程检索（`recall_read`）、识图（`image_read`）、原文回读（`thread_read`）与向用户提问（`ask_user`） |
| `web` | 联网搜索与抓取 | 联网检索（`web_search`）与网页正文提取（`web_fetch`） |
| `workspace` | 工作区与产物制作 | 工作区文件读写（`workspace_file`）、HTML 截图（`html_render`）、防幻觉图解报告（`render_report`）、附件声明（`result_attach`）以及可选资讯采编辅助（`digest_feed`） |
| `exec` | 代码与终端执行 | 在宿主工作区或隔离沙箱中执行脚本与命令（`exec_command` / `sandbox_exec`） |
| `schedule` | 定时与条件延续 | 在线程内部安排后续自唤醒与跟踪复核（`thread_later`） |

### 2. Hermes 式渐进定制与单档案 `.zip` 移植

需要特定行为规则、专属人设技能或独立常驻上下文（例如跑团主持、值守助手、项目日报官）时，可在管理台 **`档案`** 页新建或派生自定义档案：

- **首屏极简**：只需填标识、显示名称、一句话描述与作用域（`everyone` / `admins` / `listed`）；
- **按需展开高级区（`常规 | 能力`）**：按顺次配 `#1 主选 → #2 备选` 多模型回退链、选常驻或按事会话模式、开关 5 大工具集 / `SKILL.md` 技能与连接器（MCP / `@API`）；
- **`PROFILE.md` 留空自动生成**：只要填了名称与描述并将说明正文留空，系统会自动生成一份不超过 `150` 行的结构化说明初稿落盘，后续随时改写并保留版本回滚；
- **`.zip` 单档案导入导出**：替代旧版配方模板系统。导出只打包该档案自身资产与规则，自动剥离本地白名单并在打包前扫描阻断任何疑似密钥；导入支持覆盖更新（保留本机白名单与已有工作区）或另存副本。

## 三、双轨线程连续性与随时续聊

每个后台活动都有一条带 `th_...` 编号的线程记录，按能力档案的 `session_mode` 走双轨路由：

1. **按事轻量线程（`default` 默认为 `ephemeral`）**：每次发起新任务独立开启线程；近期几条直接在上下文索引里接着追改，更早的任务可通过 `maisya_recall` 查回线程号原位 `send` 或 `reopen` 续聊。
2. **同会话常驻主线（定制档案默认为 `persistent`）**：定制档案在当前会话下会自动绑定到专属常驻主线程与持久工作区（无需每次记线程号）。如需重新开一局干净现场，传 `fresh=true` 即可把旧主线归档留档并在原位另起一条新主线。
3. **随改随用，停止不锁死**：
   - 修改档案的模型、技能或工具集后，原有线程与工作区下一轮实时生效，不再因配置变动报错锁定；
   - 中途喊停（`stop`）仅取消当轮任务、修补未闭合的工具调用并将状态置回 **`idle`**，之后随时补充一句或调用 `reopen` 就能无缝接上继续跑；
   - 运行途中可随时发送补充要求或勾选 **立即转向（`steer`）**。

## 四、免容器执行与对话式风险确认（`ask_risky`）

`v0.3` 移除了必须先搭 `Docker + runsc` 才能跑命令的门槛，改为按真实触发身份自动裁决：

- **管理员私聊直通 & 宿主机工作区执行**：开启插件后，管理员私聊默认免白名单全能力可用；触发 `exec` 工具集时默认通过 `HostWorkspaceRunner` 在隔离工作区副本 `project/` 下直接运行 Python / Bash / CLI（剥离宿主无关环境，临时凭据仅在 `0o400` 私有目录单次挂载、退出即焚，输出强制脱敏）。
- **关键更改前先问一句（`ask_risky`，默认）**：当涉及删除工作区外文件、破坏性命令模式（如 `rm -rf` / `git reset --hard` / 系统服务启停）、外部写请求、敏感系统路径或首次向外部环境注入凭据时，线程会暂停进入 `waiting`，由 MaiBot 用自然口吻把待确认命令与原因转述给管理员；管理员回复同意（可选择本次放行、本线程放行、记住长期授权或拒绝）后即可继续跑完。也可在「设置」调整为 `autonomous` 或 `always_ask`。
- **群友轮次自动隔离**：开启可选 `DockerRunner` 时，非管理员执行代码自动路由至无凭据、无宿主机挂载的隔离容器；未开启 Docker 时，硬拦截普通群友的任意 Shell 拼接，仅允许安全读写工作区与调用管理员预置在 `preset/scripts/` 下的只读固定脚本。

## 五、Condition Watch 条件盯梢 & 图文报告

### 1. Condition Watch（`mode="watch"`）

不再需要维护外部签名 Webhook。管理员或启用会话可以直接口头让 MaiBot 开启一个持续盯梢任务（`every_seconds >= 300`）：

- 后台按设定的周期静默检查 `condition` 条件，并自动对照前 3 次检查摘要；
- **没变化时不打扰**：条件未命中时静默收尾，不向群聊或私聊冒泡，**也不扣减每日主动额度**；
- **命中条件才汇报**：一旦条件触发（例如监控到版本更新、新异常日志或特定变动），立即产出结论与可选图卡唤醒目标会话汇报；在管理台「现场」左侧随时可暂停、立即测试一次或取消。

### 2. 图解与网页报告（`render_report` + 技能）

保留共享技能 `research-report`、`source-checking`、`ongoing-workspace`、`news-digest` 与防幻觉组件工具 `render_report`：

- 支持输出带交互标签页的自包含网页报告 `out/*.html`（`layout="page"`），或自动展开为 780px 零脚本长图卡 `out/*.png`（`layout="card"`）；
- 传入原文摘要 `source_text` 时强制核验关键数字出处，防止数据幻觉。

## 六、四页双主题工作台与 5 步首次引导

打开 MaiBot 后台中的 **Maisya** 入口，即见自包含的 **四页工作台** 与（首次安装自动弹出的）**5 步启动引导**：

- **5 步启动引导**：按 `hello → 管理员设置 → 启用与会话 → 模型/确认策略/主题 → 就绪清单` 依次配置；提供最近私聊一键点选设管理员、8 秒限时无秘钥模型连通测试与 7 项就绪清单核验。
- **双主题切换**：默认采用协调宿主的 **千禧机械风（`millennium`）**，支持切换 **现代极简风（`modern`）** 与 **跟随宿主（`auto`）**。
- **四个页面**：
  1. **现场（Now）**：左栏「预定与盯梢」+「活动时间线（支持清理无效废记录）」，右栏垂直步骤时间线（点每一步可展开脱敏后的原始参数/命令与输出）联动上下文 Token 方块图；
  2. **档案（Profiles）**：Hermes 渐进式档案定制、5 大工具集 / 技能 / 连接器卡片、像素小鱼头像定制与 `.zip` 导入导出；手机窄屏保留顶部无框小鱼横滑切换与底部 4 栏导航；
  3. **资料库（Library）**：全会话产物画廊与预览，侧栏底部直通系统文件树安全编辑与回滚 `MEMORY.md` / `JOURNAL.md` / `HEARTBEAT.md` / 技能与工作区；
  4. **设置（Settings）**：会话开关、双源管理员与授权记忆管理、安全存储索引，以及全局模型/主动节奏/主题/Docker 开关。
