# 功能详解

[← 回到 README](../../README.md)

装上 Maisya 之后，它在群里、私聊里和 MaiBot 内嵌网页工作台里是怎么配合干活的。

---

## 一、MaiBot 当主脑，Maisya 补齐手脚与持续过程

和额外塞一个新机器人不同，Maisya 的全部设计都绕着一个中心转：**MaiBot 自己的 `planner` 就是唯一主脑与唯一发言人**。

- **日常聊天不改味**：群友聊天、接梗、日常互动和记忆印象继续走 MaiBot 原生流程与 `A_Memorix`，Maisya 在 `chat.receive.after_process` 只记录可信消息编号，绝不拦截聊天。
- **需要干活才派线程**：只有当 MaiBot 判断需要联网多步核实、长文创作、处理文件、写网页或长期跟进某件事时，才调用 `maisya_agent` 把活交到后台线程；短任务在 `20` 秒快窗内直接带着结论回来，长任务后台慢慢跑，跑完再唤醒原会话的 `planner`。
- **结果回到原人设说话**：
  - **纯文字结论**：单次垫入 MaiBot 原生 `replyer` 生成，保持它原本的口吻、拆句与表达习惯。
  - **带准确链接、图片海报或文件附件**：通过 `share` 调用宿主 `maisaka.reply.generate` 带着本轮表达意图生成一两句开场，再用 `send.hybrid` 发出去；带有普通文件附件时会在主表达之后自动跟发独立文件条，不丢不乱。

## 二、开箱三角色、多模型替补与 Skill 技能库

### 1. 三个开箱角色

| 角色 | 默认状态 | 运行环境 | 擅长干什么 |
|:-----|:-----|:-----|:-----|
| **`scout`（探索者）** | 默认启用 | 轻量只读 | 联网多源核实、读网页正文、识图、读人物/长期记忆、汇总出处；可自动生成排版简报与 HTML 图片卡 |
| **`maker`（创作者）** | 默认启用 | 沙箱 / 无容器降级可用 | 维护持久工作区 `in / project / out`、编写网页/脚本/文档、自带 `render_report` + `research-report` 输出交互报告页或 780px 图解长图卡、支持 `from_threads` 接力上游结论与成品 |
| **`digest`（资讯简报）** | 默认停用 | 轻量只读 | 专职盯每日资讯：冷启动精选初订源 + 多引擎并发广搜 `collect`、精确时间提取与五维筛选、原生 `viz_spec` 嵌入简报长图卡；无好内容时静默收尾 |

### 2. 每个角色都能按顺次配模型链与自动回退

在 **`能力 → 角色管理 → 模型与权限配置`** 里，你可以从宿主已经配好的模型池中为每个角色挑一个或多个模型，排成 `#1 主选 → #2 备选 → #3 …`：

- 运行时总是优先用 `#1`；一旦出现网关超时、限流、工具格式报错等异常，线程会保留已经完成的所有工具成果和工作区文件，立刻换 `#2` 接着往下跑，不会从零重来。
- 全留空时自动沿用该角色设定的宿主模型槽位（如 `utils` 或 `planner`）。

### 3. 围绕 `SKILL.md` 的双列技能库与工作台

在 **`能力 → 技能库`** 里，Maisya 直接把所有跨会话可复用的方法规范（`SKILL.md`）做成了画廊与编辑器：

- 开箱自带 `source-checking`（公开资料核验单）、`ongoing-workspace`（持续工作区约定）、`news-digest`（资讯简报工作流）与 `research-report`（深度调研与图文报告排版规范）。
- 点击卡片即可编辑正文、可视化调整元数据与角色绑定；支持拖拽 `.zip` / `.skill` / `.tar.gz` 压缩包或粘贴包文本导入，自带的 `references/`、`scripts/`、`assets/` 伴随文件会自动随技能按只读挂载进工作区 `in/skills/<技能名>/`。

## 三、Agent 线程、持续工作区与接力

每项后台活动在 Maisya 里都是一段有编号（`th_...`）、有完整记录的线程：

1. **随时补充与立即转向（`steer`）**：任务跑在半路你想改主意，既可以在群里直接跟 MaiBot 说，也可以打开 **`现场`** 页在活动现场输入框发送引导。普通补充逐条排队；勾选 **`立即转向`**（`steer=true`）会保留前面已提交的成果、跳过旧方向未执行的步骤，按新要求继续。
2. **需要拿主意时先问一句**：只有缺少核心输入或遇上高风险分岔时，线程才会暂停成 `waiting`，由 MaiBot 顺口向你问一句；你回答后继续接上，不瞎猜。
3. **持续命名工作区与 `from_threads` 接力**：长期专题、跑团存档、每日简报共用同一个命名工作区（如 `digest_daily`、`trip_notes`），同一时间只让一个线程写入，保证文件不被写乱。哪怕前一个线程已经停止关闭，开新线程时传 `from_threads` 也会把上游文字结论、引用附件与 `out/` 成品同步带进新线程只读 `in/` 目录继续改。

## 四、`digest` 每日资讯简报与 Intelligent UI 图解报告

### 1. `digest` 每日资讯四步工作流

开启 `digest` 并给目标群排好每日钟点计划后，每轮巡检（工作区预算自动提升到 `max_steps = 20`）会走四步流：

1. **先读本群口味与最近聊天**：看一眼该群的 `MEMORY.md` 约定（已按最新修改优先解析别名）与近期聊天热点，定这一轮搜什么、避开什么水文。
2. **一次 `digest_feed(action="collect")` 统一采编**：
   - 若冷启动尚无订阅源，从内置精选一手源目录（`STARTER_FEEDS`）按话题匹配试订最多 4 个 `trial` 源；
   - 轮询现有订阅，同时用多组中英文具体检索词走 **`WebRouter.search_broad`**（多引擎并发扇出如 EXA / Tavily / You / Anysearch / DDG），并用程序规则粗筛掉站点首页、`/2025/` 或 `/2026/` 年月归档与百科等索引页；
   - 并发抓回原文 `source_text`、通过 `page_date` 多层规则抽取精确发布时间（`<meta>` / JSON-LD / `<time>` / 正文发布行）、标记是否含可可视化数字 `has_numbers`，并在遇到带 `<link rel="alternate">` 的独立博客时顺手试订高质量 RSS。
3. **五维打分与防幻觉 `viz` 图解核验**：`score_select` 踢掉超期旧闻（资讯 >7 天、指南 >60 天或无日期）、无出处搬运；仅在确有清晰对比数据时，为条目附带克制的标准 `viz_spec` 图解（所有展示数字 `> 10` 需在 `source_text` 有依据；若个别图解核验未通过，仅丢弃该条图解并记录 `viz_dropped_reason`，绝不误杀有效新闻）。
4. **内嵌图解静态渲染出图**：`render_card_html` 直接内联 `viz.css` 与静态 `.vs-static` 图解片段（按早/午/暮/夜时段配色，零 `<script>`），再用 `html_render` 截成长图 `out/digest-card.png` 交付；零条入选时静默收尾。

### 2. `maker` 通用图解与调研报告（`render_report` + `research-report`）

做多方对比盘点、数据调研或产品梳理时，`maker`（默认已挂好 `render_report` 与 `research-report` 技能）可使用同一套 Intelligent UI 组件库（16 种模块：`stat`、`stats`、`compare`、`bars`、`line`、`share`、`timeline`、`table`、`list`、`takeaway`、`tabs` 及报告专属 `heading`、`text`、`note`、`image`、`sources`）：

- **`layout="page"`**：生成带原生轻交互标签页与严格 CSP 的自包含 HTML5 报告网页 `out/*.html`（禁止外部外链图片，支持把工作区内 `in/` / `project/` / `out/` 的安全图片校验魔数后转 base64 内联）。
- **`layout="card"`**：自动展开所有 `tabs` 为连续章节、生成 780px 零脚本静态卡片 HTML，再由 `html_render` 截成高清长图 `out/*.png` 直接发群。
- **`source_text` 防幻觉门禁**：传入 `source_text` 时，所有展示数字 `> 10` 必须能在摘录中找到原型或四舍五入容差依据，未核实直接拦截报错。

## 五、管理员私聊一句话管全局（`setup`）& 先预览再发群

哪怕管理员此刻正在与 MaiBot **单独私聊**，而这段私聊并不在 `enabled_chats` 白名单里：

- 插件会先按真实发言人核验是否属于宿主管理员；核验通过后，**只在这一轮用有界内存引导**解锁全部管理、跨群调度与全流检索工具，同时绝不把你的私人聊天写进常规群白名单表，陌生人私聊依旧零响应、零写入。
- **一段话一站到位（`maisya_shape(action="setup", kind="setup", ...)`）**：管理员说完需求后，Planner 无需东拼西凑拆七八个步骤——调用一次 `setup` 即可在单次交互中顺序完成：自动加入 `enabled_chats` 白名单、规范化免打扰时段（如 `"1:00-8:00"` 自动存为 `"01-08"`）、启用角色与分配模型（开启 `digest` 时自动补全联网与步数预算）、写入目标群最新有效 `MEMORY.md`、冷启动试订一手 RSS 源（个别源失败记入 `warnings` 而不中断全局）、以 `tz_offset_minutes=480` 替旧覆盖每日定时（同时规范 `"digest-feeds"` → `"digest"` 工作区名防止孤岛）、并按 `run_now=True` 立即发起第一期试跑。
- **私聊试跑预览，再一键推群**：让某个目标群的工作区在后台跑完一版初稿时，传 `deliver_to="current"`，结果会先单独回传到管理员的私聊确认（不在目标群留下待发记录）；你点头说好后，MaiBot 再调用 `share` 发进目标群（系统会自动拦截跨会话消息引用，避免泄露私聊上下文）。
- **个人提醒与定时工作流**：管理员在未开启的私聊里也能给 MaiBot 下个人定时提醒或定时汇总任务（标记 `admin_direct`），到点只回传提醒你本人。

## 六、能力配方（Recipe）分享与安全体检

如果你想把调教顺手的某个角色（例如「开源项目研究员」或「游戏版本追踪官」）分享给朋友，或者从 GitHub 导入别人的配置：

- **不是整库拷贝，而是「能力配方」**：打包 `PROFILE.md`、`profile.toml`、可选绑定的技能与伴随文件、方法笔记、`preset/` 初始工作区素材、角色专属小鱼头像及推荐例行调度；**自动剥离**你的群号列表（`allow_chats`）、成员列表（`allow_users`）与原会话 ID，绝不带走聊天记录、`MEMORY.md` 和保险箱密钥。
- **导出前体检**：命中保险箱里存过的真实密钥或私钥格式直接阻断导出；出现内网 IP、常见手机号/QQ号格式、邮箱或本机路径会高亮提示。
- **接收端先预览后平滑升级**：支持上传压缩包、粘贴 Base64 文本，或直接贴公开 GitHub / 压缩包链接（由后端按跳检查公网 IP 防 SSRF 后安全拉取）。导入前先体检缺少哪些模型、凭据句柄或服务；如果本地已有同名角色，可选「平滑升级」（保留你的白名单、启停开关、绑定态与旧工作区，且可一键回滚版本）或「另存新副本」。

## 七、内嵌双主题五页工作台

打开 MaiBot 后台顶部切换栏中的 **Maisya**，即可看到五个各自独立、遵守宿主 CSP 安全沙箱的管理页：

1. **现场（Now）**：`01 会话来源 → 02 主脑调度（MaiBot Planner） → 03 角色 → 04 活动与产出` 拓扑流向图、实时状态与 4 格遥测读数、五段上下文占用方块/方格图 + 示波器趋势、活动步骤流与「立即转向」引导、底部默认折叠的「临时唤醒某个角色」。
2. **产物（Outputs · 资料空间）**：左侧按 `全部 / 页面与卡片 / 图像与海报 / 文档与代码 / 结论与出处 / 持续工作区` 分类，外加 `最近 5 项` 和来源会话筛选；右侧支持搜索、列表/4 列网格切换与实时安全阅读预览、源码查看和持续工作区目录浏览。
3. **能力（Abilities）**：双列技能画廊与 `SKILL.md` 工作台、角色名册与「定制小鱼 / 随机换鱼」（12 鱼种 × 18 配色 × 11 眼神）、模型与权限配置、`NOTES.md` 版本回滚、配方模板分享导入、宿主发现只读参考。
4. **手账（Memory）**：按会话切换 `MEMORY.md`（每会话上限 2,200 字）、近 7 天 `JOURNAL.md`（上限 1,500 字）与 `HEARTBEAT.md` 探索脾性，同屏支持全维度搜索及待唤醒意图队列、自动笔记回执管理。
5. **设置（Settings）**：顶部清晰划分「一般设置 / 高级设置」，支持顶栏与设置页双向切换**千禧机械风（默认） / 清朗手账风 / 自动跟随宿主**；所有不懂的名词都藏在标题旁的小 `?` 按钮里，点开或悬停即可看白话解释。
