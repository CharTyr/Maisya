# 开发里程碑

每一阶段遵循「先写能失败的测试 → 实现最小闭环 → 本地测试通过 → 需要时跑真实宿主契约测试 → 小步提交」。

## M0：插件外壳与信任底座

**状态：基础实现完成，初始验收为本地 27 项单测与真实宿主 5 项隔离契约通过（2026-11-12）。** 请求前工具过滤已在 M1 接入 planner。具体环境与测试范围见 [开发入门](00-开发入门.md)。

- **范围**：
  - 根目录 `_manifest.json`、`webui.json` 骨架、`plugin.py` 生命周期与 `<宿主根>/data/maisya/` 初始化。
  - 可信消息映射：原始消息 ID、短别名、会话、平台、真实发言人、插件代投标记。
  - 管理员名册继承、受限工具隐藏、按 `source_msg_id` 验证真实发言人。
  - 凭据保险箱、显式 `/vault` 命令与输出脱敏。
- **验收**：本地单测通过；真实宿主隔离契约测试通过 `ManifestValidator`、WebUI 扩展加载和插件更新后外部数据保留检查。

## M1：Agent 线程与 `scout`

**状态：基础实现完成，累计本地 71 项单测与真实宿主 12 项隔离契约通过（2026-11-12）。** 线程循环和宿主接入使用测试 RPC 验证；实际模型、联网服务和群聊效果待联调。在线文档走宿主网页读取，群文件实体解析归入 M3。

- **范围**：
  - 线程存储、事件流、`active / waiting / idle / closed` 状态、按预算完整归档和本线程原文回读。
  - `maisya_agent` 的 `start / send / stop`，支持 MaiBot 自主调用普通只读能力，受限操作核验真实来源；默认 `20` 秒等待窗口，窗口结束后线程继续运行。
  - `scout` 只读能力档案：搜索、读网页、识图、读文档、查公开会话与宿主记忆。
  - `maisya_recall` 检索当前会话线程和自身线程。
  - `maisaka.planner.before_request` 剔除宿主内置 `subagent*`，保留其他工具，并追加线程索引。
- **验收**：闲聊直接回复的路由说明已接入；短任务在等待窗口内同轮返回；长任务继续运行；模型与工具边界可转向，停止和运行时限阻止后续调用；续接保留事实和出处，旧结论可搜；会话线程不跨会话泄漏。实际 planner 是否遵循闲聊路由需真实模型联调。

## M2：回接桥与现场页

**状态：回接桥、share 出口与现场页已实现，累计本地 108 项测试与真实宿主 16 项隔离契约通过（2026-11-12）。** 同步结果单次补入、原生 Replyer 重试、用户来源后台结果的持久回接、同轮汇合与停止/转向去重已验证；share 的原生表达与准确载荷发送经 SDK 与宿主契约验证；现场页支持线程列表、步骤流、上下文构成、递纸条与停止。真实对话交付效果待联调。

- **范围**：
  - `maisaka.replyer.before_request` 单次垫入纯文字结果。
  - 异步线程结果生成 `return` 意图，并按回接组汇合后唤醒原会话 `planner`。
  - `maisya_agent(action="share")`：`maisaka.reply.generate` 生成 MaiBot 原生表达，`send.hybrid` 发送准确链接、媒体和锚点。
  - 玻璃盒“现场”页：线程列表、步骤流、结果、意图、递纸条和停止。
- **验收**：纯文字只由 `reply` 发一次；含链接或媒体的结果只由 `share` 发一次；`share` 消息在后续上下文中被识别为 MaiBot 自己发言；现场页单路轮询，用户操作始终有可用并发槽。

## M3：`maker`、工作区与凭据边界

**状态：执行代码已实现，真实运行时验收通过。** 累计本地 139 项非浏览器测试、1 项 Chromium 页面测试通过；真实宿主 17 项隔离契约通过；独立 runsc 验收 `all_runtime_checks_passed` 全绿且宿主环境复核无变化（2026-11-13）。实测覆盖：固定 uid 非 root 执行、node/npm、公网依赖安装与 API、宿主/peer/元数据/内网/DNS 重绑定/IPv6/DNAT 阻断、断网模式、超时/取消/内存限制与文件回滚、受限档案 `0400` 凭据挂载与目标白名单、工作区并发续接/重载恢复/穿越与配额拒绝、三类输入实体与不可变附件、真实 stdio MCP 会话隔离与撤权、档案克隆/导出/导入。详见 [M3 执行方案](03-M3执行方案.md)。默认沙箱关闭。剩余 Pulse 持续活动 silent 唤醒与平台真实发消息/文件上传属联调范围。

- **范围**：
  - 容器沙箱执行环境、受控公网出站与离线档案、宿主/内网/元数据封锁、软链接越界防护、附件目录与结果检查。
  - 命名工作区、线程输入队列和持久活动续接。
  - 宿主机 MCP 池、管理员私有凭据单次挂载、档案包导入导出。
  - 能力档案克隆与热加载。
- **验收**：沙箱越权和内网访问被拦截；同名工作区并发补充按顺序处理；群友使用带 Key 档案时看不到密钥；导出包只含凭据句柄名。

## M4：记忆层与能力塑形

**状态：核心实现与隔离验收完成（2026-11-12）。** 本阶段验收为 151 项非浏览器测试、1 项 Chromium 页面测试与 18 项真实宿主 SDK 契约。`maisya_shape` 按真实管理员来源验证，会话记忆、近况、技能与短笔记已接入上下文和检索。后续已补入连续两次显式转向的提炼触发；摘要仅使用状态轨迹与转向次数，限 500 token，质量待真实模型联调。管理页的版本操作已在 M6 接入。

- **范围**：
  - 会话 `MEMORY.md`、自身 `JOURNAL.md`、全局技能和档案 `NOTES.md`。
  - `maisya_shape` 创建、修改、回滚能力档案、技能和会话记忆。
  - 线程笔记提炼与密钥、隐私、会话私货检查。
- **验收**：明确指正后下一次线程使用新做法；含具体会话信息的笔记不进入全局技能；所有修改可查看历史并回滚。
