# 开发里程碑（TDD 分阶段路线）

每一阶段严格遵循「先写红灯测试 → 实现最小闭环 → 本地全绿 + 契约测试全绿 → 提交」。

## M0：根目录直装空壳、外部数据目录与双道验身保险箱
- **范围**：
  - 根目录 `_manifest.json`（`chartyr.maisya`，SDK `2.8.1`–`2.21.0`，宿主 `1.0.0`–`1.4.99`）、`webui.json`（v2 骨架）、`plugin.py` 生命周期（`on_load` / `on_unload` / `on_config_update`）及 `<宿主根>/data/maisya/` 外部持久化初始化。
  - `auth_vault.py`：继承宿主管理员名册、有界可信发言人映射（兼容原 ID 与短别名 `m...`，排除 `relayed_by_plugin`）、双道防串号验身、凭据保险箱（WebUI 录入为主 + 管理员私聊显式 `/vault` 命令拦截消费，绝不盲吞日常私聊）与出站密钥脱敏闸。
- **验收**：本地单测全绿 + 服务器唯一隔离目录真实宿主 venv 契约测试全绿（含 `ManifestValidator`、`load_webui_extension` 与更新不丢外部数据核验）。

## M1：调度钩子、20 秒黄金快窗、热转向/续聊/热换模、免容器 `researcher` 与零重影交付
- **范围**：
  - `maisaka.planner.before_request`（仅剔除内置 `subagent*`，100% 保留宿主原生工具与其他第三方插件 `@Tool`；注入「闲聊常识默认直回 `reply`」的字节恒定说明块；无管理员时隐藏受限工具）与 `maisaka.planner.after_response` 轨迹采集。
  - `maisya_dispatch`（**默认 `20 秒` 黄金快窗同轮直出 + 超时或 `background=true` 并发无缝转后台**、支持 `cancel_run_id` 原子热转向、`resume_run_id` 15 分钟温热会话原房续聊、`then_profile` 专岗间产物直传免中转唤醒）+ `maisya_runs`（SQLite FTS5 `< 5ms` 检索，区分本会话 `scope="session"` 与跨会话可搜的自身经历线程 `scope="self"`）+ Python 确定性状态机守卫的 **Batch Barrier** 单次合并唤醒 + 严限硬阻断场景最多 1 次的 `NEEDS_INPUT` 挂起反问 + **429/5xx 带记忆原地热切 `fallback_models` 续跑** + 后台 `steer` 纸条队列接口。
  - 免容器 100% 纯只读 `researcher` 专岗闭环（含受权调用宿主插件 `@API`）+ `maisaka.replyer.before_request` 单次核实小抄注入 + 零重影媒体挂载（`send_service.before_send` 合并同条或仅补发纯附件，绝不双发文字；纯文字任务无条件秒收尾）。
- **验收**：快活 20 秒内当轮直出零二次唤醒，长活/并发自动转后台汇合；闲聊直回不乱派活，图文零双发重影，`scope="self"` 经历线程跨会话可检索。

## M2：容器沙箱 `worker`（查算一体）、持久 `workspace` 排队锁、对话自塑形专岗与宿主机 MCP 池
- **范围**：
  - 受限公网容器沙箱 `WorkBox`（`--read-only`、无 root、封死本机/内网/云元数据网段、软链接越界防护、**内置只读联网搜索实现查算一体**、`ref_msg_ids` 原图/合并转发/群文件装载、`from_runs` 产物续改、`here.now` 24h 预览）。
  - 会话级持久命名 `workspace`（含同名工作区 FIFO 串行排队锁防并发写坏存档，支持长线跑团/项目续改/多站虚拟旅行）与管理员单次 `/run/secrets/<handle>` `0400` 只读挂载。
  - `profiles.py` 自定义派生专岗（`<宿主根>/data/maisya/profiles/<id>/` 热生效，支持管理员通过 `maisya_skill` 对话自塑形或管理台编辑）、**无明文密钥 `.zip` 专岗+技能配方包导入导出**与宿主机侧持 Key 的 MCP 进程池（二进制产物转短句柄旁路直通）。
- **验收**：沙箱越权/内网探测拦截测试全绿，`worker` 单房查算一体闭环，群友触发带 Key 派生专岗及导出 `.zip` 配方包全程零密钥暴露、零 Base64 进上下文。

## M3：2,200 字冻结记忆、多卡 `SKILL.md` 与 Hermes 双轨复盘
- **范围**：
  - 每会话 `MEMORY.md`（2,200 字硬上限、快照冻结保缓存、仅管理员可写 `maisya_memory`）与预设 `platform-delivery`、`virtual-travel` 等基础 Skill。
  - `maisya_skill` 对话内即时修卡/塑形专岗 + 多步摩擦/报错重试后台 `< 500` token 异步提炼。
  - 四道安全闸（含拦截单群私货混入全局 `SKILL.md`）：旧卡小补丁自动生效并留历史版本一键回滚，新卡进 `pending` 草稿箱。
- **验收**：Prompt 注入/密钥/单群私货/越界内容 100% 被四闸拦截，顺畅一步查询零额外复盘调用。

## M4：三源头会话原生心跳（`HEARTBEAT.md` + `JOURNAL.md`）、多站行程推进与社交分寸硬闸
- **范围**：
  - `pulse.py` 统一脉搏循环：三源头心跳（对话余韵 Afterglow + 冲浪偶遇 Serendipity + 久违想念，按会话 `quiet`/`care`/`lively` 三档主动度筛选后调 `maisaka.proactive.trigger` 唤醒**目标会话原生 `planner`**）、`<= 1,500` 字近 7 天滚动心境手账 `JOURNAL.md`（记 MaiBot 自身视角主观近况，脱敏具体群友隐私）、`maisya_schedule` 到期检查（区分闲聊事后惦记与绑定 `workspace` 的多站静默行程推进，`[NO_CHANGE]` 静默结束）与按需开启的超薄 `Webhook` 验签口。
  - 代码级焊死「睡眠免打扰 + 按 `session_id` 未回不连戳 + 熟人私聊边界」，经 `chat.open_session` + `maisaka.proactive.trigger` 自然唤醒。
- **验收**：连戳按 `session_id` 独立锁死与解锁、睡眠跳过、陌生人私聊阻断、心境手账零隐私外泄、多站旅行行程推进与 `maisya_runs` 经历检索全链路测试通过。

## M5：MaiBot 原生 WebUI 玻璃盒工作区（4 个自包含 `custom` 页面）
- **范围**：
  - `webui/live.html`（实时流向圆点动画、专岗步骤流、**后台无痕「递纸条（Live Steer）」输入框**与一键中止、按面积比例渲染的 Context Map 方块地图、心跳脉搏与 `JOURNAL.md` 心境随笔，采用单路游标串行轮询严守 `inflight <= 2`）。
  - `webui/profiles.html`（含专岗 `.zip` 配方包一键导入导出）、`webui/skills.html`、`webui/settings.html` 及对应静态 `@API` 接口，自动跟随宿主亮/暗主题与原生 `confirmation` 确认弹窗。
- **验收**：在模拟宿主 `CSP connect-src 'none'` + `window.maibot` MessageChannel 沙箱下的真浏览器（Playwright Chromium）交互、并发限流与响应式测试全绿。
